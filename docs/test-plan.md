# MVP 测试计划

## 当前实现的执行入口（2026-11-17）

- `npm test`：离线自动回归，覆盖协议、代码/图片透传、失败、缓存及取消。
- `npm run test:host`：隔离 HOME 的生产插件加载。
- `npm run probe -- provider/model`：真实网关原账户 JSON/SSE 探针。
- `npm run test:live -- provider/model`：隔离宿主同实例回环和真实原生目标合成请求，翻译使用固定替身。

目标模型可选 Codex 等原生模型，不再限于 Claude。实测证据与未完成验收以 [P0 报告](p0-report.md) 为准；自动测试通过不等于真实翻译质量/性能已通过。

## 环境与原则

- 使用隔离的 MAGPIE HOME 测试插件加载，避免覆盖用户现有配置。
- 真实 Claude 账户测试前确认目标模型，不展示和记录任何鉴权内容。
- 使用固定可复现 fixture，覆盖 JSON、SSE 分帧边界和图片摘要对比。
- P0 先通过真实端到端闭环，再实现完整功能；所有失败必须保留测试编号。

## P0 核心测试

| 编号 | 测试输入 | 预期结果 |
|---|---|---|
| P0-01 | 安装虚拟 Provider 并请求其模型 | MAGPIE 加载成功，能触发插件 fetch |
| P0-02 | 插件内调用 /v1/messages 的原生 Claude 模型 | MAGPIE 复用现有账号且不递归 |

| P0-06 | SSE 文本块拆为随机字节 chunk | 输出合法 SSE，中文可读 |
| P0-07 | tool_use / tool_result | IDs、顺序、JSON 参数完全一致 |
| P0-08 | 思考块、签名、缓存/usage 字段 | 不翻译、不篡改 |
| P0-09 | 流中断和取消 | AbortSignal 传播、资源释放 |

| P0-11 | 非目标模型请求 | 不经过翻译层 |
| P0-12 | 翻译模型返回无效占位符 | 校验失败并阻断 Claude 调用 |

## P1 质量与性能

- 100 条中文开发需求 + 50 条混合指令 + 30 条代码/JSON/Shell 样本。
- 比对翻译前后路径、变量、命令、HTTP 状态、数值、专有名词和 Markdown。
- 10/50/100 并发压力测试；测量翻译输入与输出 token、TTFT 增量、p50/p95、失败率。
- 多轮历史回放、压缩上下文、工具调用迭代与 Claude Code 子 Agent 场景。
- 安全测试：API Key 泄漏扫描、SSRF、恶意提示词令占位符失效、日志中隐私泄漏。
